# Archive Quest

Карта-приложение, где ты сохраняешь точки по всему миру (архивные и винтажные магазины, аниме-фигурки, храмы, винил, кафе и что угодно ещё) и закрываешь их как квесты. Стиль — японский archive core.

## Что умеет

- **Карта** с тёмными тайлами, бирками точек, поиском и фильтром по категориям.
- **Точки-квесты**: у каждой есть задачи с XP. Квест закрывается по геолокации в радиусе 100 м, а без гео — с половиной XP.
- **Квест-линии**: точки с одинаковой линией (например, «Урахара») собираются в цепочку, за закрытую линию дают +200 XP.
- **Ранги** как у следователей: Rank 3 → Rank 2 → Rank 1 → First Class → Associate Special → Special Class. Растут сами от XP.
- **ZERO-CLASS 零** — уникальный ранг основателя. Включается в «Профиль → Настройки» кодом основателя. Основатель ведёт отряд и подписывает «приказы» о присвоении ранга, а друг принимает приказ по ссылке.
- **Категории**: 9 готовых и свои.
- **Штампы** закрытых точек, стрик, фото точек, бэкап в файл.

## Как поставить на iPhone

1. Открой сайт в **Safari**.
2. Нажми «Поделиться» → **«На экран Домой»**.
3. Запусти с иконки и разреши геолокацию.

## Офлайн

После первого открытия приложение работает без сети: точки, квесты, ранги, штампы. Карта офлайн показывает районы, которые ты уже смотрел онлайн (кэш до 4 000 тайлов). Перед поездкой пролистай нужный район на тех масштабах, что понадобятся.

## Важно

- Сейчас все данные хранятся **только в браузере телефона**. Делай бэкап в «Профиль → Настройки».
- Приказы о ранге передаются ссылкой и ничем не защищены, как и код основателя. Это прототип: настоящая защита и общий отряд появятся вместе с сервером (например, Supabase).

## Разработка

Чистый HTML/CSS/JS без сборки. Локально:

