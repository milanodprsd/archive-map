# Archive Quest

Карта-приложение, где ты сохраняешь точки по всему миру (архивные и винтажные магазины, аниме-фигурки, храмы, винил, кафе и что угодно ещё) и закрываешь их как квесты. Стиль — японский archive core.

## Что умеет

- **Карта** с тёмными тайлами, бирками точек, поиском и фильтром по категориям.
- **Точки-квесты**: у каждой есть задачи с XP, третья — случайный бонус из 15 вариантов (можно один раз сменить). Квест закрывается по геолокации в радиусе 100 м, а без гео — с половиной XP.
- **Квест-линии**: точки с одинаковой линией (например, «Урахара») собираются в цепочку, за закрытую линию дают +200 XP.
- **Ранги** как у следователей CCG. Подробно — в разделе «Как устроены ранги» ниже.
- **Приказы 辞令** — вкладка с бланками приказов: текст, подпись основателя и печать. Новый приказ приходит со значком на вкладке.
- **Отметки мест**: 占 «захвачено» (был, второй раз не нужно) и 禁 «запретно» (не ходить). **Запретные зоны** — красные круги на карте, телефон предупреждает, когда заходишь внутрь.
- **Стили карты**: XEROX (светлая ч/б, по умолчанию) и NIGHT (тёмная). На дальнем зуме подписи прячутся.
- **Категории**: 9 готовых и свои.
- **Штампы** закрытых точек, стрик, фото точек, бэкап в файл.

## Как устроены ранги

| Ранг | Как получить |
|---|---|
| Rank 3 三等 | у всех на старте |
| Rank 2 二等 | 500 XP или приказом |
| Rank 1 一等 | 1 500 XP или приказом |
| First Class 上等 | 3 000 XP или приказом |
| Associate Special 准特等 | 6 000 XP или приказом |
| Special Class 特等 | 12 000 XP или приказом |
| 9th Division 玖 | только приказом основателя, один человек на весь мир |
| **ZERO-CLASS 零** | **только основатель приложения, один на весь мир** |

- Каждый, кто открывает приложение, начинает с **Rank 3**, не с ZERO-CLASS.
- **ZERO-CLASS** получает только тот, кто первым нажал «Я ОСНОВАТЕЛЬ» на сервере отряда. Это уже сделано, поэтому у всех остальных этой кнопки больше нет, а сервер не даст второму стать основателем.
- **Свой отряд может создать любой**: Профиль → Отряд → «Создать свой отряд». Создатель становится командиром 班長: зовёт друзей по ссылке, видит их аватарки и место на карте и может исключить. Командир начинает с Rank 3, как все, и ранги не выдаёт: в его отряде ранги растут только от XP. Отряды не видят друг друга. Если командир уходит, командиром становится самый опытный участник.
- Ранг растёт сам от XP за закрытые точки. Приказы о рангах подписывает только ZERO-CLASS своему отряду: любой ранг до Special Class или особый 玖. Приказ приходит во вкладку «Приказы». Ранг по приказу действует, пока человек в этом отряде (玖 остаётся всегда). Действует старший из двух рангов: по XP или по приказу.



1. Открой сайт в **Safari**.
2. Нажми «Поделиться» → **«На экран Домой»**.
3. Запусти с иконки и разреши геолокацию.

## Офлайн

После первого открытия приложение работает без сети: точки, квесты, ранги, штампы. Карта офлайн показывает районы, которые ты уже смотрел онлайн (кэш до 4 000 тайлов). Перед поездкой пролистай нужный район на тех масштабах, что понадобятся.

## Отряд онлайн (Supabase)

Аватарки друзей, их ранги и местоположение на карте работают через общий сервер Supabase (бесплатный тариф).

1. Создай проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query**: вставь весь файл [`supabase/schema.sql`](supabase/schema.sql) и нажми **Run**.
3. **Authentication → Sign In / Providers → Email**: выключи **Confirm email**. Вход по почте и паролю, письма не нужны: на бесплатном тарифе Supabase шлёт мало писем, а шаблоны без своего SMTP не редактируются.
4. **Project Settings → API**: скопируй Project URL и ключ `anon public` в [`config.js`](config.js).
5. В приложении: Профиль → Настройки → «Отряд онлайн» → почта и пароль (первый вход создаёт аккаунт). Основатель на вкладке «Отряд» жмёт «Я ОСНОВАТЕЛЬ» (срабатывает только у первого) и зовёт друзей ссылкой `#/join/КОД`.

Что защищено правилами базы: ZERO-CLASS только у одного человека, ранги выдаёт только основатель и только своему отряду, свой ранг поднять нельзя, место видят только участники твоего отряда. Место отправляется, только пока включён переключатель «Показывать моё место отряду» и открыто приложение; выключение удаляет его с сервера. XP пока считается на телефоне, поэтому его можно подкрутить.

## Важно

- Сейчас все данные хранятся **только в браузере телефона**. Делай бэкап в «Профиль → Настройки».
- Ранги и основатель проверяются сервером Supabase. Офлайн-режим без сервера (если `config.js` пустой) остался только для копий приложения без отряда.
